몬스터 배틀 JRPG — 전투·성장 시스템 처음부터 설계

2026.09 · 오리지널 IP · 전투 공식 / 스탯 설계 / 웹 구현
정통 JRPG 파티 구조(탱커 · 물리딜러 · 마법딜러/힐러 3인)를 오리지널 몬스터로 재구성해, 전투 공식부터 레벨 성장 곡선까지 직접 설계하고 웹으로 구현해 실제 플레이 가능한 상태까지 만들었습니다.
  • 대미지 공식을 3차례 재설계 — ATK를 모든 공격의 기본값으로 두고, 힘/지력을 스킬별 계수(coefs)로 분리해 스킬마다 물리/마법 배분을 독립적으로 가질 수 있는 구조로 일반화
  • "가치 검증" 표를 직접 만들어 탱커/물리딜러/마법딜러 3종족의 종합 전투력을 Lv1·Lv30 기준 100% / 100% / 100%로 정확히 맞춤 (ATK·DEF·HP·힘·지력의 환산 배율을 역산해서 결정)
  • 보스를 고정 개체 대신 "무작위 몬스터 + 별도 결정한 보스 배율"로 처리해 콘텐츠 확장에 유연하게 대응
  • 포켓몬식 전투 UI와 타격 연출까지 구현해, 수치가 실제 플레이 감각으로 이어지는지 직접 확인

밸런스 수치 시각화 툴

2026.09 · 독립 웹 도구 · Vanilla JS + Chart.js
특정 게임에 종속되지 않고, 엑셀로 수치를 굳히기 전에 "감"을 먼저 잡아보기 위한 범용 도구입니다. 기준 스탯 → 대미지 공식 → 성장 곡선 → 가치 환율 → 경험치 곡선을 하나의 마법사로 잇고, 몬테카를로 시뮬레이션 · 가챠 천장 · 장비 파밍을 부록으로 분리했습니다.
  • 패널 간 수치가 자동으로 이어지도록 설계하되, 어디까지 연동시키고 어디서 끊어야 설계 자유도가 남는지 직접 판단해서 구조를 잡음
  • 전투를 자동으로 반복 시뮬레이션해 DPS·치명타·TTK를 실시간으로 보여주고, "승률이 같아도 분산이 다르면 체감이 다르다"는 걸 그래프로 직접 확인할 수 있게 구성
  • 기능을 바꿀 때마다 jsdom으로 실제 DOM 동작을 자동 검증하며 개발

붕괴: 스타레일 역기획서

2026.09 · 상용 라이브 서비스 게임 역기획
실제 서비스 중인 상용 게임의 전투 수치를 공식 위키·인게임 데이터로 역산해, 방어 공식·성장 곡선· 육성 비중·유물 옵션 가중치까지 정량적으로 분석하고 개선안을 제안했습니다.
  • DEF = 200 + 10×Lv 등 실제 공식을 데이터로 역산해서 검증하고, 곱셈형 방어 공식의 구조를 정리
  • 레벨업 : 광추 : 유물 육성 비중을 1 : 0.8 : 2로 정량화
  • SPD 부옵션 가중치를 4→5로 올리는 개선안을 확률 계산으로 검증 — 체감 등장률 19.6%→23.7%, 목표 도달에 필요한 개수 5.1개→4.21개

Project-Idle-Runtime — 사이버펑크 방치형 게임 기획

사이버펑크 방치형 성장 게임 · 기획 + 서버(C++ IOCP)·클라이언트(Unity) 직접 구현
해커가 되어 거대 기업("메가코프")의 서버를 해킹하는 사이버펑크 방치형 게임. 핵심 루프는 해킹(자동/수동) → 크레딧 획득 → 하드웨어·악명(환생) 업그레이드 → 상위 티어 해킹이며, 경제·성장·소셜/라이브·UI/UX를 각각 별도 문서로 기획하고 실제 서버·클라이언트까지 직접 구현했습니다.
  • CPS(초당 크레딧 획득량) 중심의 경제 구조 — 자동 해킹(실시간 CPS)과 수동 클릭(위협도의 5% 추가 데미지)을 같은 재화로 수렴시켜 하이브리드 방치형 루프를 설계
  • 메가코프 서버 해킹을 5단계 보안 레이어(방화벽 → 게이트키퍼 → 메인프레임 등)로 나누고, 보스전 실패 시 이전 단계로 후퇴해 파밍 모드로 전환되는 진행 로직 설계
  • CPU/RAM/Network 3축 하드웨어 성장 시스템과 시각적 피드백(LED 색상·배경 변화)을 별도 문서로 정리
