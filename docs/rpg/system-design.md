# [가제] 몬스터 배틀 JRPG — 전투/성장/경제 시스템 기획서

> 관련 문서: `RPG_밸런스기획서.xlsx` (수치·수식), `RPG_설계결정서.xlsx` (결정 근거 로그)

## 1. 개요

### 1.1 배경 / 목적
전투·시스템 기획 포트폴리오용으로, JRPG를 직접 설계·구현·플레이 테스트한다. 분석 위주였던 역기획서(`붕스 역기획/`)와 달리, 이 프로젝트는 직접 설계하고 구현해서 플레이까지 해보고 다시 고치는 과정을 보여주는 게 목적이다.

### 1.2 게임 한 줄 정의
커맨드형 턴제 전투를 중심으로, 필드·던전 탐험과 성장을 결합한 웹 기반 몬스터 배틀 JRPG. 플레이어는 탱커 / 물리딜러 / 마법딜러·힐러 역할의 오리지널 몬스터 3마리로 파티를 이끈다 (역할당 1마리 — 직업 대신 몬스터 종족을 쓴다는 점 외에는 정통 JRPG 파티 구조와 동일. 포획/교체 같은 실제 포켓몬식 메커닉은 채택하지 않는다).

### 1.3 레퍼런스
드래곤 퀘스트, 파이널 판타지 초기작 (커맨드형 턴제 구조) + 포켓몬 시리즈 (몬스터 종족·속성 상성 체계, IP는 쓰지 않고 구조만 참고)

## 3. 용어 정리

| 용어 | 정의 |
|---|---|
| 라운드 | 전투 참여자 전원이 한 번씩 행동하는 단위. 행동력(10000/속도) 기준으로 순서가 정해진다 (B2) |
| 조우 | 필드/던전 이동 중 무작위로 전투가 시작되는 것 |
| TTK | Time To Kill, 적 하나를 처치하는 데 걸리는 평균 턴 수 |
| 벤치마크 분할 | 레벨업을 기준(1)으로 두고 다른 육성 루트(장비 등)의 비중을 비교하는 방식 (책 3.3.2) |
| 원탁이론 | 확률형 판정(치명타/회피/도망 등)을 우선순위대로 하나의 "원탁"에 배치해 순서대로 판정하는 방식 (B3에서 채택) |

## 4. 전체 흐름

### 4.1 게임 진행 흐름
마을(상점·회복) → 필드(조우) → 던전(조우 + 고정 배치) → 보스 → (클리어)

### 4.2 전투 흐름
전투에 들어가면 선공/조우 판정을 하고, 행동력(=10000/속도)이 작은 쪽부터 순서대로 행동한다(B2). 각자 커맨드(공격/스킬/아이템/방어/도망)를 입력하면 라운드가 처리되고, 전투 종료 조건을 만족할 때까지 반복한다.

스킬은 MP 없이(B6) 바로 선택·대상 지정 후 대미지 공식(B4)을 태운다. 대미지는 곱셈 공식으로 계산하고(최소 대미지 보정 없음), 속성 약점/내성 배율(B7: 약점 ×1.5, 내성 ×0.7)을 곱한 다음, 치명타/회피/도망을 원탁이론으로 판정해서(B3) 최종 대미지를 적용하고 사망 판정을 한다.

## 5. 상세 기능 명세

각 항목은 결정 번호(`RPG_설계결정서.xlsx`)를 표시한다. **[결정 대기]**로 표시된 항목은 수치/규칙이 아직 없다.

### 5.1 전투 시스템

| 항목 | 규칙 | 결정 번호 | 밸런스 시트 연동 |
|---|---|---|---|
| 속성 체계 | 1·3단계(레벨 성장): HP, ATK, DEF, 속도, 힘, 지력, 치료효율 / 2단계(종족 고정값): 크리티컬확률·크리티컬피해·물리피해·마법피해·물리저항·마법저항·회피 | B1 | `RPG_밸런스기획서.xlsx` > 1_스탯테이블 |
| 행동 순서 | 행동력 = 10000/속도, 행동력이 작은 쪽부터 행동 (붕괴: 스타레일 역기획에서 가져옴) | B2 | - |
| 확률 판정 (치명타/회피/도망) | 원탁이론: 우선순위대로 하나의 원탁에 배치해 순서대로 판정 | B3 | 3_전투시뮬레이터 |
| 대미지 공식 | 곱셈 공식. 대미지 = ATK × (1 − 방어율), 방어율 = DEF/(DEF+방어상수K). 최소 대미지 보정 없음 | B4 | 3_전투시뮬레이터 |
| 마법 방어(MDEF) 여부 | 있음 — DEF의 하위 분류로 물리저항/마법저항이 존재 | B5 | 1_스탯테이블 |
| 스킬 공식 (배율/자원 소모) | MP 없음 (자원 관리로 인한 복잡도 상승을 피하기 위해 제외) | B6 | 3_전투시뮬레이터 |
| 속성 약점/내성 배율 | 불/물/풀/땅 4속성. 약점 ×1.5, 내성 ×0.7. 어떤 속성이 어떤 속성에 강한지(상성표)는 결정 대기 | B7 | 4_몬스터테이블 |

예외 처리(결정 후 채움): 대미지가 0 이하일 때 처리(현재 최소 대미지 보정 없음 → 0 또는 음수 가능성 확인 필요), 전원 사망 시 처리 등.

### 5.5 UI 흐름 (화면 목록 — 초안)

타이틀 → 마을(메뉴: 상점 / 여관 / 필드 이동) → 필드/던전(이동 + 조우) → 전투 화면(커맨드 선택 → 로그 출력) → 결과 화면(승리/패배) → 마을로 복귀
