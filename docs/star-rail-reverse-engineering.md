## 1. 정의 (Definition)

- **장르/테마**: 턴제 RPG
- **한 줄 정의**: 속도 기반으로 턴을 잡는 턴제 전투. 아군 캐릭터 4명의 공격 또는 상호작용으로 택틱을 최적화하여 상대 파티를 격파하는 것이 핵심이다.
- **왜 이런 방식을 택했을 것 같은지**: 턴제를 택한 이유는 "재밌을 것 같아서" 정도밖에 떠오르지 않는다.

**다른 턴제 RPG 대비 차별점**
1. 공유 자원 (전투 스킬 포인트)
2. 궁극기 사용의 자유도 (다른 캐릭터의 턴에도 궁극기 사용 가능)

턴이 왔을 때 할 수 있는 행동이 일반 공격, 스킬 공격, 궁극기 사용 세 가지뿐이다. 그래서 라이트하게 즐기는 사람은 깊게 생각하지 않고 편하게 플레이할 수 있고, 헤비 유저는 스킬 포인트 관리와 궁극기 타이밍 같은 디테일로 판단의 깊이를 챙길 수 있다.

## 2. 구성 (Composition)

전투 진입부터 종료까지의 큰 흐름을 "전투 플로" 개념(기초 / 스킬 / 대미지)으로 나눈 것이다.

### 기초 플로

| 단계 | 내용 |
|---|---|
| 전투 진입 | 파티원 배치, 적 배치, 각자 초기 행동력 계산해서 턴 순서 정하기, 필살기 게이지 초기값 세팅 |
| 데이터 초기화 / 패시브 처리 | 유물 세트효과, 패시브 특성 적용, 패시브 비술 처리 (전투 사전에 쓰는 스킬) |
| 턴 순환 | 액티브 비술 처리 (첫 번째 턴 시작 시에만) → 행동력이 낮은 순서대로 턴이 돌아옴 → 스킬 포인트 회복 → 그 턴에 기본공격 / 스킬 / 궁극기 중 선택 → 결과에 따라 다음 행동력 재계산 |
| 전투 종료 | 적 전멸 또는 아군 전멸 시 종료, 버프 / 게이지 초기화 |

### 스킬 플로

| 종류 | 흐름 |
|---|---|
| 전투스킬, 일반스킬 | 일반공격 / 스킬 사용 → 대상을 지정하고 스킬 시작 → 스킬 공식에 따라 데미지 계산 → 스킬 발동 → 스킬 끝 |
| 패시브 스킬 | 특정 조건일 때 시작 → 스킬 공식에 따라 수치 계산 → 스킬 발동 → 스킬 끝 |
| 궁극기 | 궁극기 사용 → 현재 턴이 궁극기 사용자의 턴이면 바로 발동, 아니면 바로 다음 턴에 예약 → 궁극기 턴이 오면 대상을 지정하거나 하지 않고 발동 → 궁극기 시작 → 궁극기 수치 계산 → 궁극기 발동 → 궁극기 끝 |

### 대미지 플로

![대미지 공식](image.png)

해당 식에 맞게 데미지 계산 → 디버프 효과 명중 / 저항 계산 → 흡혈 판단 → 대상에게 데미지 → 대상 사망 판단 → (부활이나 사망이 아닐 시) 후속타 / 패시브 발동 조건 검사 후 발동 → 데미지 출력

일반 속성(공방체 + 2단계 확률형 속성)과 비일반 / 특수 속성(속도, 격파 등 이 게임 고유 시스템)으로 나뉜다. **자세한 목록은 3.1 참고.**

## 3. 상세 (Detail)

### 3.1 속성 정의

| 구분 | 설명 | 속성 |
|---|---|---|
| 1단계 | 전투에 직접 영향 | ATK, DEF, HP |
| 2단계 | 백분율, 대미지에 직접 영향 (치명 / 저항 / 관통 등) | CRIT Rate, CRIT DMG, Effect Hit, Effect RES, Debuff RES, DMG RES, DMG Mitigation, RES Penetration |
| 3단계 | 1·2단계 수정용 | Outgoing Healing Boost, DMG Boost, Final DMG Boost, Vulnerability |
| 특수 | 속도 등 장르 고유 | Speed, Break Effect, Energy, Energy Regeneration Rate, Toughness, Aggro |

### 3.2 전투 구조 — 턴 / 행동순서

**턴 결정 방식** (속도 스탯 → 행동순서 변환 공식)

```
SPD(최종 속도) = Base SPD × (1 + SPD%) + Flat SPD
행동력(Action Value) = 10000 / SPD
```

- SPD 공식은 강의에서 배운 "속성 총합 공식"(초기값 × (1 + 백분율) + 고정값)과 같은 형태다.
- 행동력이 **낮을수록** 먼저 턴이 온다 (SPD가 높을수록 10000 / SPD가 작아지므로).

**확률형 2단계 속성(치명 등)의 판정 방식** — 확률론 / 원탁이론 중 어느 쪽에 가까운지

**둘 다 아닌 것으로 추정.** 확률론과 원탁이론은 "회피 / 일반 / 치명 / 관통처럼 서로 배타적인 결과가 하나의 100% 확률 공간을 나눠 쓴다"는 전제가 있는데, 스타레일 공식에는 그런 경쟁 구조가 보이지 않는다.
- 기본 공격에 "회피(빗나감)" 개념 자체가 없다. 치명타가 경쟁할 상대가 없다.
- → 스타레일은 **각 2단계 속성이 독립적으로 판정되는 방식**(확률론 / 원탁이론보다 단순한 제3의 방식)에 가깝다.

#### (2) 성장 곡선 추정

#### (3) 육성 루트 분할 추정 (레벨업 vs 광추 vs 유물)

**기준**: 히메코 노바 80레벨 + 5성 광추(80레벨) + 유물 5성(+15, 주옵션만 반영). 유물 랜덤 부옵션은 캐릭터 / 빌드마다 달라서 제외한 **추정치**다. (책 3.3.2 "벤치마크 분할 방식": 레벨업을 기준으로 다른 육성 루트의 비율을 비교)

| 구성 요소 | HP | ATK | DEF | SPD | 비중 (ATK 기준) |
|---|---:|---:|---:|---:|---:|
| 캐릭터 80레벨 (레벨업 루트) | 1124 | 756 | 485 | 98 | 22.7% |
| 광추 (별이 밤하늘을 밝힐 때 / 5성) | 847 | 635 | 529 | 0 | 19.0% |
| 유물 고정 주옵션 (머리: HP / 손: ATK) | 705 | 352 | 0 | 0 | 10.6% |
| 유물 %·SPD 주옵션 (몸 / 신발 / 구 / 줄) | 0 | 86.4% (→ 1201.8) | 0 | 0 | 36.0% |
| 행적 (패시브 보너스) 등 기타 | 0 | 28% (→ 389.5) | 0 | 0 | 11.7% |
| **합계** | 2676 | 3334.3 | 1014 | 98 | 100% |

- ATK% 환산: 기초 ATK(캐릭터 756 + 광추 635 = 1391) × % → 유물 1391 × 86.4% = 1201.8, 행적 1391 × 28% = 389.5
- 검산: 1391 × (1 + 0.864 + 0.28) + 352 = 3334.3
- HP 합계 = 1124 + 847 + 705, DEF 합계 = 485 + 529 (HP%, DEF% 보너스 없음). 비중은 ATK 기준만 계산.
- 레벨업을 1로 놓으면 광추 0.84 : 유물(고정 + %) 2.06 : 행적 0.52

**결론**
- 레벨업 : 광추 : 유물 ≈ **1 : 0.8 : 2**. 레벨과 광추를 합친 것보다 유물의 공격력 비중이 더 컸다 (신발을 속도로 끼는 경우에는 더 낮아진다). 유물은 공격력 %를 주기 때문에 영향이 아주 컸다.
- SPD는 광추의 옵션, 다른 캐릭터의 버프, 행적, 유물을 통해 얻을 수 있다.

### 3.5 AI / 난이도 — 적 스탯

적(보스 / 일반 몬스터) 스탯이 레벨에 따라 어떻게 커지는지 관찰했다.

> **출처**: Honkai: Star Rail Wiki(Fandom)의 HP/Data, DEF/Data, ATK/Data, Damage RES 문서. 공식 수치는 인게임에 표시되지 않아 위키의 커뮤니티 데이터를 사용했고, 표에는 Lv1과 Lv90 값만 있어 중간 레벨 곡선은 확인하지 못했다.

#### (1) 적 HP: 기준값(레벨) × 몹 종류별 배수

배수 1×의 적 기준: Lv1 = 93, Lv90 = 21,998

| 배수 | 적 예시 | Lv1 HP | Lv90 HP |
|---:|---|---:|---:|
| 1× | Birdskull (Dreamjolt Troupe) | 93 | 21,998 |
| 1.5× | Astropolis Sentinel | 140 | 32,997 |
| 2.5× | Grunt: Field Personnel 계열 (Assistant Graffiti 등) | 233 | 54,994 |
| 3× | Alloy Pommy | 279 | 65,993 |
| 12× | Abundance Sprite: Malefic Ape | 1,116 | 263,973 |
| 15× | Argenti (Boss) | 1,395 | 329,966 |
| 60× | The Giver, Master of Legions, Lance of Fury | 5,580 | 1,319,864 |
| 500× | Guide of Withering and Decay | 46,500 | 10,998,864 |

- 확인한 범위에서 **Lv90 ÷ Lv1 ≈ 236.5배**로 적 종류와 상관없이 같았다 → 레벨 성장 곡선은 모든 적이 공유하고, 몹 등급 차이는 배수로 표현하는 구조로 추정 (강의의 "기준 능력치 × 몬스터별 배수"와 같은 설계).

#### (2) 적 DEF: 기준값 = 200 + 10 × 적 레벨

| 적 구분 | Lv1 DEF | Lv90 DEF | 배수 |
|---|---:|---:|---:|
| 대부분의 적 (일반 몹 · 엘리트 · 보스 전부 동일) | 210 | 1,100 | 1× |
| Trotter 계열 (Warp Trotter, Sequence Trotter 등) | 315 | 1,650 | 1.5× |

- 검산: 200 + 10 × 1 = 210, 200 + 10 × 90 = 1,100 → 표와 일치. Trotter는 210 × 1.5 = 315, 1,100 × 1.5 = 1,650으로 일치.
- HP는 종류별 배수가 1× ~ 500×로 크게 벌어지는데 **DEF는 거의 모든 적이 같다** → 적 종류 간 차이를 HP로 만들고, DEF는 레벨에 따라서만 오르는 설계로 추정 (예외: Trotter 1.5×).
- 3.3의 DEF 배율과 연결: 공격자 레벨 = 적 레벨이면 `DEF 배율 = (Lv+20) / ((Lv+20) + (Lv+20)) = 0.5`로, DEF 무시 없이도 레벨과 상관없이 항상 50%다 (Trotter 1.5×면 0.4).

#### (3) 적 ATK: 대부분 Lv1 = 18, Lv90 = 663

| 적 구분 | Lv1 ATK | Lv90 ATK | 기준(18 / 663) 대비 |
|---|---:|---:|---:|
| 대부분의 적 (일반 몹 · 엘리트 · 보스 전부) | 18 | 663 | 1× |
| 일부 예외 (Gepard (Complete), Nebula Devourer, Planeshred Claws, Worldpurge Tail 등) | 15 | 552 | 약 0.83× |
| 일부 예외 (Flying Sword (Illusion), Silvermane Lieutenant (Complete) 등) | 20 | 736 | 약 1.11× |
| 일부 예외 (Ternary Assimilation Unit, Mr. Domescreen (Projection)) | 6 | 221 | 약 0.33× |

- 예외 적도 Lv90 ÷ Lv1 ≈ 36.8배로 같아서, ATK도 모든 적이 **같은 레벨 곡선**을 쓰는 구조로 추정.
- HP(1× ~ 500×)와 달리 **ATK와 DEF는 적 종류와 상관없이 거의 같다** → 적 종류 차이는 HP 배수로 만들고 ATK / DEF는 레벨로만 성장한다. 적이 주는 실제 피해 차이는 스킬 배율에서 나올 것으로 추정 (미확인).
- 3.4의 검증: 위키상 히메코 노바 ATK Lv1 = 102, Lv80 = 756, 광추(A Star That Lights the Night) Lv80 = 635로 3.4 표와 일치.

#### (4) 적 RES (속성 저항)

- 일반적으로 **약점 속성 0%, 그 외 속성 20%**. 종말의 환영(Apocalyptic Shadow) 적은 약점이 아닌 속성에 최소 40%. 적마다 RES가 개별로 다르므로 표로 정리하지는 않았다.
- 3.3의 RES 배율 `1 − (RES − RES 관통)`에 넣으면 약점 공격은 ×1.0, 비약점은 ×0.8 (관통 없을 때) → **약점 속성을 쓰면 피해가 25% 더 크다** (1.0 ÷ 0.8). 약점 시스템이 대미지 공식의 곱셈 항 하나로 구현되어 있다는 관찰.

#### (5) 성장 배율 비교 (Lv1 → 최고 레벨)

| 대상 | HP | ATK | DEF |
|---|---:|---:|---:|
| 적 (Lv1 → Lv90) | 약 236.5배 | 약 36.8배 | 약 5.2배 |
| 캐릭터 (Lv1 → Lv80) | 약 7.3배 | 약 7.4배 | 약 7.3배 |

- 적 성장이 캐릭터 레벨 성장보다 훨씬 가파르다. 이 차이는 광추 / 유물 / 스킬 배율 같은 곱셈 요소가 메우는 것으로 추정한다 (3.4 결론과 연결). 단, 레벨 범위(80 / 90)가 달라 단순 비교는 조심해야 한다.

#### (6) 콘텐츠별 적 레벨 — 환란의 봉오리: 모조 꽃받침 (인게임에서 직접 확인)

| 난이도 | 적 레벨 | 적 수 | 직전 난이도 대비 레벨 | 적 DEF (200 + 10 × 레벨) | DEF 배율 (Lv80 캐릭터 기준) |
|---:|---:|---:|---:|---:|---:|
| 1 | 16 | 3 | - | 360 | 0.735 |
| 2 | 32 | 3 | +16 | 520 | 0.658 |
| 3 | 40 | 3 | +8 | 600 | 0.625 |
| 4 | 48 | 3 | +8 | 680 | 0.595 |
| 5 | 56 | 3 | +8 | 760 | 0.568 |
| 6 | 66 | 3 | +10 | 860 | 0.538 |

- DEF 배율 = `(공격자 Lv + 20) / ((적 Lv + 20) + (공격자 Lv + 20))`, 공격자 Lv80 기준 (직접 계산).
- 난이도 1 → 6에서 적 레벨은 약 4.1배(16 → 66), 적 DEF는 약 2.4배(360 → 860)로 오른다. Lv80 캐릭터가 주는 피해는 DEF 항만으로 난이도 1 대비 약 27% 줄어든다 (0.735 → 0.538). HP는 중간 레벨 곡선을 몰라 계산하지 못했다.
- 난이도 간 레벨 차이는 균등하지 않다 (1 → 2가 +16으로 가장 크고, 이후 +8 ~ +10). 난이도가 올라가도 적 수는 3마리로 고정이라, 난이도 조절을 적 수가 아니라 적 레벨로만 한다.

**한계 (확인하지 못한 것)**
- 적 스킬 배율: 인게임에 수치가 표시되지 않아 확인하지 못했다. 그래서 "적이 주는 피해 차이는 스킬 배율에서 나온다"는 3.5(3)의 해석은 추정으로만 남는다.
- 적 레벨은 환란의 봉오리 한 콘텐츠만 확인했고, 다른 콘텐츠(혼돈의 기억 등)는 확인하지 못했다.

## 4. 내가 기획자라면 — 개선 제안

### 4.1 이 시스템의 장점

- 명중 / 회피 개념이 없어서 확률론이나 원탁 알고리즘 없이 스탯을 설계할 수 있다 (3.2).
- 대부분의 공식이 곱셈 공식이라 한계효용이 걸려서 수치가 안정적이다 (3.3).
- 몬스터 기본 스탯은 그대로 두고 배수만 조절해서 난이도 조절이 간단하다 (3.5).
- 유물 주옵션(%스탯)을 받지 못하면 상승폭이 큰 %를 못 받기 때문에 유물의 필요성을 느끼게 설계했다 (3.4: 유물이 ATK 비중의 약 46.6%, 그중 %가 36.0%).
- 속도 옵션의 수급처를 제한해서 유물 파밍(엔드 콘텐츠)의 소모 속도를 늦춘 것으로 **추정**된다.

### 4.2 아쉬운 점 / 개선하고 싶은 부분

- 속도 옵션을 맞추려면 랜덤성이 짙은 유물 파밍을 해야 해서 불쾌감을 유발할 수 있다.
- 다만 이 파밍이 BM(유물 파밍을 더 쉽게 해주는 상품)과 연결되어 있을 것으로 **추정**되므로, 파밍 수요 자체를 크게 줄이는 변경은 어렵다 (제약 조건, 근거 확인 필요).

### 4.3 개선 제안

#### 제안 1. 속도 옵션 파밍의 불쾌감 완화 (파밍 수요는 유지)

- **문제**: 속도 옵션의 수급이 어렵다(수급처가 광추, 행적, 신발 주옵션 등으로 제한 되어 있음. SPD 부옵션 가중치가 12개 중 최저(4)).
- **제약**: BM과 연결된 파밍 수요를 유지해야 한다 (추정).
- **변경안**: 유물 부옵션 중 SPD의 선택 가중치를 **4 → 5**로 상향한다 (나머지 부옵션 가중치와 신발 SPD 주옵션 확률 12%는 그대로).
  - 근거 데이터: 위키 Relic/Stats 문서의 부옵션 가중치 (HP · ATK · DEF · HP% · ATK% · DEF% 10, SPD 4, CRIT Rate · CRIT DMG 6, Effect Hit Rate · Effect RES · Break Effect 8, 합계 100). 커뮤니티 이론값이라 **추정치**다.
- **예상 효과**: 5성 유물의 최종 부옵션 4줄, 가중치 기반 비복원 추출로 직접 계산했다.

| 항목 | 현재 (가중치 4) | 변경 (가중치 5) |
|---|---:|---:|
| 유물 1개가 SPD 부옵션을 가질 확률 (머리 기준) | 19.6% | 23.7% |
| SPD 부옵션이 붙은 유물 1개를 얻는 데 필요한 평균 유물 수 (1 ÷ 확률) | 약 5.1개 | 약 4.2개 (약 17% 감소) |
| 6부위 한 세트의 SPD 부옵션 기대 줄 수 | 1.15줄 | 1.40줄 |
| 한 세트에 SPD 부옵션이 0줄일 확률 | 27.8% | 20.4% |
| 한 세트에 SPD 부옵션이 2줄 이상일 확률 | 32.6% | 42.5% |

  다른 부옵션이 나올 확률은 상대적으로 약 1.0 ~ 1.2% 줄어든다 (예: 치명타 28.2% → 27.9%, ATK% 43.1% → 42.7%).
- **부작용**: 속도 옵션 파밍의 완화로 유물 파밍 난이도를 쉽게 해주는 BM의 매출이 떨어질 수 있다.

#### 제안 2. 레벨 성장 곡선 (레벨이 오를수록 능력치 상승폭을 키워 성장 체감을 높인다)

- **문제**: 레벨에 따라 오르는 스탯이 선형적이라 성장의 역치를 느끼기 힘들다.
  - 근거 수치: 3.4에서 레벨업 비중 22.7%, 1 → 20 구간은 레벨당 증가량이 작고 20 이후는 거의 일정하다.
- **변경안**
  - 곡선: 3차 함수. t = (레벨 − 1) / 79 일 때 `스탯 = Lv1 값 + (Lv80 값 − Lv1 값) × (0.6·t + 0.4·t³)` (현재 표와 Lv1, Lv20 값이 거의 같도록 계수 0.4로 설정)
  - 총 성장량: 유지 (Lv1과 Lv80 값은 그대로)
  - 목표 비중: 유지 (Lv80 레벨업 ATK 비중 22.7% 그대로). 바꾸는 것은 중간 레벨의 상승 곡선이고 최종 체급은 그대로 둔다. 1, 80레벨의 스탯 수치를 고정하여 레벨업 비중은 건드리지 않는다.
- **예상 효과**

| 레벨 | HP 현재 → 변경 | ATK 현재 → 변경 | DEF 현재 → 변경 | SPD |
|---:|---|---|---|---:|
| 1 | 153 → 153 | 102 → 102 | 66 → 66 | 98 |
| 20 | 298 → 299 | 200 → 200 | 128 → 129 | 98 |
| 30 | 436 → 386 | 293 → 259 | 188 → 167 | 98 |
| 40 | 573 → 487 | 386 → 327 | 247 → 210 | 98 |
| 50 | 711 → 607 | 478 → 408 | 306 → 262 | 98 |
| 60 | 849 → 750 | 571 → 504 | 366 → 324 | 98 |
| 70 | 986 → 921 | 664 → 619 | 425 → 397 | 98 |
| 80 | 1124 → 1124 | 756 → 756 | 485 → 485 | 98 |

  레벨당 ATK 증가량: 현재 20 이후 약 9.3으로 일정 → 변경안은 구간별로 5.9 → 6.8 → 8.1 → 9.6 → 11.5 → 13.7로 점점 커진다 (Lv20~30 → Lv70~80).
- **부작용**: 레벨 중반 구간에서 캐릭터가 약하다고 느낄 수 있다 (이때는 보통 유물을 제대로 안 끼기 때문에 더 크게 느껴질 수 있다).
